# Gulf Breeze HVAC — Brand kit

Fictional Southwest Florida HVAC demo brand. Calm coastal trust, cool relief, not kitschy beach clipart.

## Logo

| File | Use |
|------|-----|
| `/brand/logo-mark.svg` | Favicon-adjacent mark, avatar wells, 24–64px |
| `/brand/logo-wordmark.svg` | Light headers, print sheets |
| `/brand/logo-mark-white.svg` | Navy headers, dark heroes |
| `/brand/logo-wordmark-white.svg` | Dark sticky nav / footer |

Mark motif: breeze arcs + cool droplet on a rounded navy→teal tile. Keep clear space ≈ 1/4 mark height.

## Type

**Primary (shipped):** Geist Sans (UI/body/display) + Geist Mono (stats, codes, demo labels).

**Alternatives if swapping stacks:**
- Display: Fraunces or Outfit (friendly, modern coastal)
- Body: Source Sans 3 or Inter
- Mono: JetBrains Mono or IBM Plex Mono

Weights: 400 body, 600 buttons/labels, 750–800 headlines. Tracking slightly tight on H1 (`-0.02em`).

## Buttons / CTA

Match existing globals:

- **Primary (`.btn-primary`):** pill, `linear-gradient(135deg, #f97316, #ea580c)`, white label, soft coral shadow. Hover: lift + brightness.
- **Secondary (`.btn-secondary`):** pill, translucent white / teal border on navy; on sand use white fill + teal border (`#0e7490`).
- **Focus:** aqua ring `#14b8a6` with offset.

Never use coral for large fills behind long paragraphs — reserve for CTAs.
